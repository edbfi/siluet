# Poyo.ai Z-Image

**V1 · Approved by council under the owner’s delegation on 2026-11-22.** Add the first production image model beyond Seedream. The owner can generate from a prompt or edit one public reference URL, review the request offline, queue once, follow it in Jobs and reopen the saved image offline. This extends [Image Studio](SPEC-image-studio.md) and the [first saved image](SPEC-first-saved-image.md) under [D2](decisions.md#d2--full-image-and-video-model-coverage).
