# ToAPIs image models and operations

Ordinary rows use JSON `POST /v1/images/generations`. The documented request requires `model` and `prompt` unless the row describes an exception. Text and reference modes share the submit path. Optional controls and input representations are model specific. Every row has the exact model ID where given, and the linked reference contains the complete accepted values and validation rules. The [task and upload contract](README.md) applies to ordinary rows. [Image task status](https://docs.toapis.com/docs/en/api-reference/tasks/image-status), [public model catalog](https://docs.toapis.com/docs/en/api-reference/models#image-models-41).

## Midjourney

`POST /v1/midjourney/generations` defaults to `imagine`; append `/{action}` for specific actions. Send `model: "midjourney"`. Inputs are public URLs, with a 12 MiB image limit. Common optional settings include `speed` and `version`. Submissions return a ToAPIs task ID. Use that ID for `GET /v1/midjourney/{task_id}`, the generic `GET /v1/tasks/{task_id}` alias, and follow-up requests. The specialized status values include `NOT_START`, `SUBMITTED`, `IN_PROGRESS`, `MODAL`, `SUCCESS` and `FAILURE`. Results can contain grids, individual image/video URLs, action buttons, prompts or a description. `MODAL` awaits a mask. Cancellation is unavailable. [Midjourney overview](https://docs.toapis.com/docs/en/api-reference/images/midjourney/generation), [query](https://docs.toapis.com/docs/en/api-reference/images/midjourney/query), [workflow](https://docs.toapis.com/docs/en/api-reference/images/midjourney/workflow).

| Action | Required inputs and distinguishing options |
| --- | --- |
| `imagine`, `edits` | Prompt. Edits also requires `image_urls`. Imagine returns a grid and action buttons. Optional controls include reference images, size, speed, version, style, quality, seed and prompt tuning. [Imagine](https://docs.toapis.com/docs/en/api-reference/images/midjourney/imagine), [Edits](https://docs.toapis.com/docs/en/api-reference/images/midjourney/edits). |
| `blend`, `describe` | Blend takes 2–4 image URLs. Describe takes at least one and returns text in `description`. [Blend](https://docs.toapis.com/docs/en/api-reference/images/midjourney/blend), [Describe](https://docs.toapis.com/docs/en/api-reference/images/midjourney/describe). |
| `upscale`, `variation`, `high-variation`, `low-variation` | Parent `task_id` plus `index` or a returned button's `custom_id`. Standard indexes are 1–4. Strong and subtle variation usually use an upscaled image. [Upscale](https://docs.toapis.com/docs/en/api-reference/images/midjourney/upscale), [Variation](https://docs.toapis.com/docs/en/api-reference/images/midjourney/variation), [High](https://docs.toapis.com/docs/en/api-reference/images/midjourney/high-variation), [Low](https://docs.toapis.com/docs/en/api-reference/images/midjourney/low-variation). |
| `reroll`, `zoom`, `pan` | Parent `task_id`. Reroll optionally takes speed and button ID. Zoom requires an upscaled parent and optionally takes `zoom_ratio`. Pan requires direction. [Reroll](https://docs.toapis.com/docs/en/api-reference/images/midjourney/reroll), [Zoom](https://docs.toapis.com/docs/en/api-reference/images/midjourney/zoom), [Pan](https://docs.toapis.com/docs/en/api-reference/images/midjourney/pan). |
| `inpaint`, `modal` | Start with the Upscale `task_id`. Once the new task enters `MODAL`, submit its ID and a public `mask_url`, with an optional revised prompt. [Inpaint](https://docs.toapis.com/docs/en/api-reference/images/midjourney/inpaint), [Modal](https://docs.toapis.com/docs/en/api-reference/images/midjourney/modal). |
| `remix-strong`, `remix-subtle` | Successful v8.1/v8.2 parent, `index`, and an optional prompt. [Remix](https://docs.toapis.com/docs/en/api-reference/images/midjourney/remix). |
| `video` | One image URL or a successful parent ID and index. Optional `batch_size` 1/2/4 changes the charge. Query `video_urls`. [Video](https://docs.toapis.com/docs/en/api-reference/images/midjourney/video). |
