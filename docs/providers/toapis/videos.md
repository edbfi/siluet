# ToAPIs video models and operations

The default submit path below is JSON `POST /v1/videos/generations`. Send the exact `model` listed. Rows call out distinct prompt and media requirements, routes and options. A field such as `image_urls` can denote a first frame, keyframes, or unordered reference images depending on the model and mode. The linked reference defines accepted combinations. See the [task and upload contract](README.md). [Video task status](https://docs.toapis.com/docs/en/api-reference/tasks/video-status), [public catalog](https://docs.toapis.com/docs/en/api-reference/models#video-models-54).

## Vidu

| Model IDs | Documented operations and input differences |
| --- | --- |
| `viduq3-pro-fast` | Requires prompt and at least one image. Only the first image is used as the first frame. Audio defaults to true, watermark to false, duration to 5 seconds, and resolution to `720P` with `1080P` also documented. Optional seed and metadata. [Vidu Q3 multi-model](https://docs.toapis.com/docs/en/api-reference/videos/vidu-ali/generation). |
| `viduq3-ad`, `viduq3-drama`, `viduq3-mix` | Require prompt and reference material. The documented starting combination is a video via `url` or `video_list[].video_url` plus at least one image via `image_urls` or a listed compatibility field. Video entries can carry `refer_type` or `keep_original_sound`. Drama recommends `1080P` and explicit `audio`. The page warns that upstream structured subjects may still be required but supplies no exact subjects payload for these IDs. Its failed-task example reports `InvalidParameter` and includes `completed_at` despite the general status reference describing that timestamp for successes. [Vidu Q3 multi-model](https://docs.toapis.com/docs/en/api-reference/videos/vidu-ali/generation). |
| `viduq3-pro`, `viduq3-turbo` | Required prompt, then zero images for text, one for first frame, two for first/last. Optional 1–16 seconds, `540p`/`720p`/`1080p`, ratio, audio, seed and Q3 metadata. [Vidu Q3](https://docs.toapis.com/docs/en/api-reference/videos/viduq3/generation). |
| `viduq3` | Required prompt and up to seven reference images in `image_urls`, with optional structured `metadata.subjects` containing names and images and `@name` references in the prompt. Up to seven subjects and three images per subject. 3–16 seconds. The Q3 page also documents audio and voice controls, webhook and off-peak mode with a 48-hour generation window and refund on expiry where supported. Vidu documents billing by model, resolution and generation type. [Vidu Q3](https://docs.toapis.com/docs/en/api-reference/videos/viduq3/generation). |
| `viduq4-preview` | Required prompt. First-frame mode requires exactly one image. Reference mode accepts up to 15 reference images and up to three audio URLs in `metadata.sounds`. The docs give no audio-only example or minimum image count for that mode. Select explicitly with `video_generation_mode` or by media fields. Optional 3–16 seconds, `540p` through `4K`, audio, seed and watermark. Bills by output resolution and seconds. [Vidu Q4 Preview](https://docs.toapis.com/docs/en/api-reference/videos/viduq4-preview/generation). |

The multi-model Q3 page lists `input_reference`, `reference_images`, `images` and `image` as compatibility fields for `image_urls`. It gives examples of passthrough keys under `metadata.input` for first frame, last frame and audio URLs, and under `metadata.parameters` for audio and watermark. Exact alias shapes, metadata support per model, allowed duration ranges, seed bounds and SKU pricing for these four IDs remain unverified. The separate Q3 subjects schema applies to `viduq3`. [Vidu Q3 multi-model](https://docs.toapis.com/docs/en/api-reference/videos/vidu-ali/generation), [Vidu Q3](https://docs.toapis.com/docs/en/api-reference/videos/viduq3/generation).

## Seedance

| Model IDs | Documented operations and input differences |
| --- | --- |
| `doubao-seedance-1-0-pro-fast`, `doubao-seedance-1-0-pro-quality`, `doubao-seedance-1-5-pro` | Required prompt, with text or image/frame generation. Optional `image_urls` or explicit `image_with_roles`, duration, ratio, resolution and seed. 1.5 documents audio and camera lock. Use each guide's resolution and duration rules. [1.0](https://docs.toapis.com/docs/en/api-reference/videos/doubao-seedance/generation), [1.5](https://docs.toapis.com/docs/en/api-reference/videos/doubao-seedance-1-5/generation). |
| `seedance-2`, `seedance-2-fast`, `seedance-2-mini` | Text, first frame, first/last frames, and multimodal reference generation. Prompts describe the requested result, and reference combinations have explicit role and exclusion rules. Optional audio generation, last frame, web search when permitted, callback, business ID and trace ID. Mini caps references at 9 images, 3 videos and 3 audio clips. Standard/Fast video and audio counts depend on channel. [Seedance 2](https://docs.toapis.com/docs/en/api-reference/videos/seedance-2/generation). |
| `seedance-2-5`, `seedance-2-5-flash` | Text, first/last frame modes, multimodal reference including audio-only, and `video_operation` for edit/extend. Editing and extension require a video reference. Edit fixes `duration=-1`; extension duration refers to the total output. Standard allows up to 30 images, 10 videos and 10 audio clips at 480p/720p/1080p. Flash limits these to 10/5/5 and 480p/720p. Optional formatting, audio generation, last-frame return, callback and IDs. [2.5](https://docs.toapis.com/docs/en/api-reference/videos/seedance-2-5/generation), [Flash](https://docs.toapis.com/docs/en/api-reference/videos/seedance-2-5-flash/generation). |
| `seedance-2-5` draft and final | Same generation path for both. Initial `draft: true` uses normal prompts and media to produce a billed 480p MP4. Final requires a successful `draft_task_id` no more than seven days old, with draft support still enabled on the channel. Omit prompt and media for the 1080p final, which is billed separately. Flash lacks this option. [Draft mode](https://docs.toapis.com/docs/en/api-reference/videos/seedance-2-5/draft). |
| `seedance-2-ext`, `seedance-2-fast-ext` | Text or reference-image generation with `seconds`, ratio `size` and `reference_image` or `reference_images`. The suffix is part of the model name. The guides describe generation rather than extension of an existing video. [2 Ext](https://docs.toapis.com/docs/en/api-reference/videos/seedance-2-ext/generation), [2 Fast Ext](https://docs.toapis.com/docs/en/api-reference/videos/seedance-2-fast-ext/generation). |
| `seedance-2.5-ext` | Text and multimodal reference generation at fixed 720p. Uses `seconds`, `size` and reference/role fields. Audio requires an image or video. A 15-second request excludes video, audio, and more than ten image references. Frame, edit, and extend modes are unavailable. [2.5 Ext](https://docs.toapis.com/docs/en/api-reference/videos/seedance-2-5-ext/generation). |
| `seedance-2-global`, `seedance-2-fast-global`, `seedance-2-mini-global`, `seedance-2-5-global` | Catalog lists these IDs and the status guide describes some Global timing metadata. Exact ID-specific input schemas, supported operations and model parity remain unverified. [Public catalog](https://docs.toapis.com/docs/en/api-reference/models#video-models-54), [video status](https://docs.toapis.com/docs/en/api-reference/tasks/video-status). |

Some Seedance channels perform asset review on the normal media fields before submitting upstream. The task stays queued during review, and a round can take up to 20 minutes by default. A rejected or timed-out review fails the task, with no video-generation fee for failed review. Review channels reject legacy `asset://` references and apply additional URL validation. [Seedance 2 asset review](https://docs.toapis.com/docs/en/api-reference/videos/seedance-2/generation#asset-review), [2.5 review](https://docs.toapis.com/docs/en/api-reference/videos/seedance-2-5/generation#asset-review), [1.5 review](https://docs.toapis.com/docs/en/api-reference/videos/doubao-seedance-1-5/generation#asset-review).

## Other video families

| `gemini-omni-1.1-flash-preview`, `gemini-omni-1.2-flash-preview` | Submit with `POST /v1/videos` and poll `GET /v1/videos/{id}`. Require prompt. Text, up to five reference images, or dedicated `first_image_url` and `last_image_url`. 1.1 uses 10 seconds at 720p or 1080p. 1.2 uses 4–15 seconds at 720p. [1.1 Standard](https://docs.toapis.com/docs/en/api-reference/videos/gemini-omni-flash/generation-1-1), [1.2 Standard](https://docs.toapis.com/docs/en/api-reference/videos/gemini-omni-flash/generation-1-2). |

Optional `generation_type` disambiguates image modes. Omit duration and seconds with video input. [1.1 VIP](https://docs.toapis.com/docs/en/api-reference/videos/gemini-omni-flash/generation-1-1-vip). |
| `gemini-omni-flash-preview-official`, `gemini-omni-1.1-flash-preview-official` | Ordinary generations path. Require prompt. Text, images, reference video, editing and extension. Accept up to 10 images and three `video_list` entries, and document data URIs for video inputs on these routes. Optional `metadata.task`, sampling and interaction controls. Extension requires source video and excludes `previous_interaction_id`. [Omni Official](https://docs.toapis.com/docs/en/api-reference/videos/gemini-omni-flash-preview-official/generation), [1.1 Official](https://docs.toapis.com/docs/en/api-reference/videos/gemini-omni-1.1-flash-preview-official/generation). |
| `grok-video-1.0` | Requires prompt. Text, first-frame URL via `image`, and reference-image generation. Separate `POST /v1/videos/{video_id}/extend` and `/remix` actions require parent video ID and prompt. [Generate](https://docs.toapis.com/docs/en/api-reference/videos/grok-video/generation), [Extend](https://docs.toapis.com/docs/en/api-reference/videos/grok-video/extend), [Remix](https://docs.toapis.com/docs/en/api-reference/videos/grok-video/remix). |
| `grok-video-1.5` | Text, one first frame via `image` or `input_reference`, or 1–7 `reference_images` as URLs or URL objects. Text/reference modes require prompt and new first-frame requests should include it. Set `video_generation_mode` to disambiguate one reference from a first frame. First-frame semantics and 1080p availability depend on channel. Reuse of 1.0 follow-up actions remains unverified. [Grok Video 1.5](https://docs.toapis.com/docs/en/api-reference/videos/grok-video-1.5/generation). |
| `grok-imagine-video-official` | Text, first-frame or image-reference video, with required prompt and optional duration, resolution and ratio. Extension requires prompt and either a parent ID at `POST /v1/videos/{video_id}/extend` or `video_urls` at `POST /v1/videos/extend`. Pricing distinguishes output resolution and duration, input images, and the input source duration on extension. [Generate](https://docs.toapis.com/docs/en/api-reference/videos/grok-imagine-video-official/generation), [Extend](https://docs.toapis.com/docs/en/api-reference/videos/grok-imagine-video-official/extend). |
| `grok-imagine-video-1.5-official` | First-frame only as the documented mode, with required prompt and `image`. The same page lists optional `reference_images` and a cap of seven total despite describing a single input image. Additional-image behavior remains unresolved. Supports 1–15 seconds and 480p/720p/1080p. Extension is unavailable. [Grok Imagine 1.5 Official](https://docs.toapis.com/docs/en/api-reference/videos/grok-imagine-video-1.5-official/generation). |
| `happyhorse-1.1` | `action` distinguishes text, first-frame image, image-reference and video edits. First-frame mode can omit prompt. Other modes require prompt; reference mode takes 1–9 images and edits require `url` with up to five optional images. Options include `audio_setting` for edits, duration, resolution, ratio, seed and watermark. [HappyHorse 1.1](https://docs.toapis.com/docs/en/api-reference/videos/happyhorse/generation). |
| `kling-v2-6`, `kling-v3` | Text, image references, first/last frames and mixed inputs with required prompt. `reference_images` and `image_with_roles` select the semantics. Optional mode, duration, ratio, audio, negative prompt and watermark. [v2.6](https://docs.toapis.com/docs/en/api-reference/videos/kling-2-6/generation), [v3](https://docs.toapis.com/docs/en/api-reference/videos/kling-v3/generation). |
| `kling-3.0-turbo` | Required prompt for text or image-to-video and optional `reference_images`, resolution, duration, aspect ratio and watermark. [3.0 Turbo](https://docs.toapis.com/docs/en/api-reference/videos/kling-3.0-turbo/generation). |
| `kling-v3-omni`, `kling-video-o1` | Required prompt. Text, frames, image/video/element references, and mixed subject and motion input. Prompt tokens such as `<<<video_1>>>` bind to `video_list`, with images and elements in their specific metadata arrays. Optional mode, duration, ratio, audio controls and watermark. [v3 Omni](https://docs.toapis.com/docs/en/api-reference/videos/kling-v3-omni/generation), [Video O1](https://docs.toapis.com/docs/en/api-reference/videos/kling-video-o1/generation). |
| `kling-4.0`, `kling-4.0-flash` | Required prompt for text, reference media, or isolated frame mode. Accept up to ten image and five video references using URL lists or role objects. v4 allows first/middle/last keyframes with duration-dependent limits. Flash allows only one explicit first frame. Reference media and frame modes exclude each other. Optional original sound preservation, business ID, duration, resolution and ratio. [v4](https://docs.toapis.com/docs/en/api-reference/videos/kling-4.0/generation), [v4 Flash](https://docs.toapis.com/docs/en/api-reference/videos/kling-4.0-flash/generation). |
| `MiniMax-H3`, `MiniMax-H3-Highspeed`, `MiniMax-H3-Lite`, `MiniMax-H3-Max`, `MiniMax-H3-Max-Turbo` | Required prompt. Text, first frame and first/last frames across all five. Other than Max-Turbo, models also support image/video/audio references. Lite requires a specific ratio for multimodal references. H3 has distinct resolution limits and Max variants start at five seconds. Max-Turbo is outside the dated snapshot. [MiniMax H3](https://docs.toapis.com/docs/en/api-reference/videos/minimax-h3/generation). |
| `MiniMax-Hailuo-02`, `MiniMax-Hailuo-2.3`, `MiniMax-Hailuo-2.3-Fast` | 02 supports text (requires prompt), first frame, and first/last via `metadata.last_frame_image`. 2.3 supports text and first frame; Fast requires first frame. 2.3 versions require prompt. Controls include resolution/duration pairs, camera directives, prompt optimizer, fast preprocessing and watermark. [02](https://docs.toapis.com/docs/en/api-reference/videos/minimax-hailuo/generation), [2.3 and Fast](https://docs.toapis.com/docs/en/api-reference/videos/minimax-hailuo-2.3/generation). |
| `sora-2-vvip`, `sora-2`, `sora-2-pro` | VVIP generation requires prompt, supports image and character references, and exposes optional thumbnail, batch and storyboard controls. [VVIP](https://docs.toapis.com/docs/en/api-reference/videos/sora2/generation), [Remix](https://docs.toapis.com/docs/en/api-reference/videos/sora2/remix), [Create character](https://docs.toapis.com/docs/en/api-reference/videos/sora2/create-persona), [Character status](https://docs.toapis.com/docs/en/api-reference/videos/sora2/get-personas). |
| `veo3.1-fast`, `veo3.1-lite` | Required prompt. Text, frame-driven and image-reference generation with optional `metadata.generation_type`, duration fixed at eight seconds, and 720p or 1080p for Lite. [Veo standard](https://docs.toapis.com/docs/en/api-reference/videos/veo3/generation). |

[Wan 2.6](https://docs.toapis.com/docs/en/api-reference/videos/wan2.6/generation), [2.6 Flash](https://docs.toapis.com/docs/en/api-reference/videos/wan2.6-flash/generation). |

[Wan 3.0](https://docs.toapis.com/docs/en/api-reference/videos/wan3.0/generation). |
| `midjourney` | Uses the [Midjourney action and status routes](images.md#midjourney). Starts from one URL or a successful parent task and index. [Midjourney Video](https://docs.toapis.com/docs/en/api-reference/images/midjourney/video). |
